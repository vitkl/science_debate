## Installation

You need to have Python 3.11 or newer installed on your system.
If you don't have Python installed, we recommend installing [uv][].

There are several alternative options to install science_debate:

<!--
1) Install the latest release of `science_debate` from [PyPI][]:

```bash

```
-->

1. Install the latest development version:

```bash
pip install git+https://github.com/vitkl/science_debate.git@main
```
